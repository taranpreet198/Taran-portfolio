## 🚀 How to Run the Website Locally in VS Code

### Method A: Using VS Code "Live Server" (Recommended)
1. Open **Visual Studio Code**.
2. Click **File > Open Folder...** and select this project directory (`c:\Users\animation_lab\Taran`).
3. If you haven't installed it yet, install the **Live Server** extension:
   - Click the Extensions icon on the left sidebar (or press `Ctrl + Shift + X`).
   - Search for **Live Server** (by Ritwick Dey) and click **Install**.
4. Right-click on `index.html` in the file explorer and select **"Open with Live Server"**.
5. Your default web browser will automatically open at `http://127.0.0.1:5500/index.html`. Any edits you make in the code will reload live!

### Method B: Directly in Any Web Browser (No installation needed)
1. Open Windows File Explorer and navigate to `c:\Users\animation_lab\Taran`.
2. Double-click `index.html`.
3. It will open instantly in your default web browser (Chrome, Edge, Firefox, Brave, etc.).

## ✏️ How to Customize Your Details (Editable Placeholders)

Every placeholder is marked with comments in `index.html`. Open `index.html` in VS Code and use `Ctrl + F` to search and update the following:

| Section | What to Search For | What to Replace It With |
| :--- | :--- | :--- |
| **Education** | `[Your College / University Name` | Replace with your college name (e.g., *Guru Nanak Dev University, Amritsar*) |
| **Graduation Year** | `[Expected: 2026/2027]` | Replace with your actual expected year of graduation |
| **12th School** | `[Your School / Junior College` | Replace with your high school or junior college name and passing year |
| **Email Address** | `taranpreet.singh@example.com` | Replace with your real contact email (it appears in both text and `mailto:` links) |
| **LinkedIn** | `linkedin.com/in/taranpreet-singh-placeholder` | Replace with your personal LinkedIn profile URL |
| **GitHub** | `github.com/taranpreet-singh-placeholder` | Replace with your personal GitHub username/link |
| **Resume PDF** | `assets/resume-sample.html` | Put your finalized `resume.pdf` into the `assets/` folder and change the button link to `assets/resume.pdf` |

## 🌐 How to Deploy Your Website Online for FREE

Here are the three easiest, zero-cost ways to put your portfolio on the internet so recruiters can view it:

### 🌟 Option 1: GitHub Pages (Most Recommended for Developers)
1. Create a free account at [github.com](https://github.com) if you haven't already.
2. Click the **`+`** icon in the top right corner and choose **New repository**.
3. Name the repository: `<your-username>.github.io` (for example: `taranpreet-singh.github.io`) or simply `portfolio`.
4. Leave it **Public** and do NOT check "Add a README file" (you already have one).
5. Click **Create repository**.
6. Upload your files:
   - On the empty repository page, click **"uploading an existing file"**.
   - Drag and drop all project files (`index.html`, `README.md`, and the `css`, `js`, and `assets` folders).
   - Click **Commit changes**.
7. Enable GitHub Pages:
   - Go to your repository's **Settings** tab.
   - On the left sidebar, click **Pages**.
   - Under **Build and deployment > Branch**, select `main` (or `master`) and folder `/ (root)`, then click **Save**.
8. Within 1–2 minutes, your website will be live at:
   `https://<your-username>.github.io/` or `https://<your-username>.github.io/portfolio/`.

---

### ⚡ Option 2: Netlify Drop (Fastest — Under 1 Minute, No Git Required)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Sign up for a free Netlify account (or log in with Google/GitHub).
3. Drag the entire `Taran` folder and drop it into the designated box on the Netlify webpage.
4. Netlify will deploy your site in seconds and give you a free live URL (e.g., `https://taranpreet-portfolio.netlify.app`).
5. You can customize the subdomain name under **Site Configuration > Change site name**.

---

### 🚀 Option 3: Vercel (Blazing Fast & Professional)
1. Go to [vercel.com](https://vercel.com) and sign up with your GitHub account.
2. Click **Add New... > Project**.
3. Select your GitHub repository for the portfolio.
4. Leave all build settings default (since it is pure HTML/CSS/JS, no build step is needed).
5. Click **Deploy**.
6. Your portfolio will be live at `https://your-project.vercel.app` with automatic free SSL and global CDN distribution.
